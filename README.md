# Aprendiendo portugués

Curso de portugués para hispanohablantes, de A1 a C2. Clases, audios, diccionario, libros y certificados. La interfaz sigue el mismo recorrido del template: tres etapas, práctica escrita y autoevaluación.

## Local

1. Copiá `config.example.php` a `config.php` y completá la base.
2. Visitá `/aprendiendoportugues/index.php/instalar?key=LA_SEED_KEY`.

## Contenido

El léxico y las clases salen de `python scripts/build_portugues.py`.
Los audios, de `python scripts/generate_audio.py`.
